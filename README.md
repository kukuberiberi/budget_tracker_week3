# 💰 Modern Budget Tracker - Visual Design Project

## Overview
This repository contains the visual design enhancement for the **Budget Tracker** application. Built entirely with CSS3, this project elevates a functional layout into a clean, modern, and user-friendly interface using professional design systems without adding new HTML structures.

---

## 🎨 Implementation Highlights & Rubric Alignment

1. **Intentional Color Palette (25%)**
   - Utilizes a cohesive design token system via CSS variables (`:root`).
   - Features a primary **Indigo (`#4f46e5`)** accent color paired with clean slate neutrals (`#f8fafc` background, `#0f172a` text) for a professional financial application aesthetic.

2. **Typography & Hierarchy (20%)**
   - **Outfit** Google Font applied to all headings (`h1` - `h6`) and table headers for strong visual weight.
   - **Inter** Google Font applied consistently across body text, form elements, buttons, and table rows to ensure ultimate readability and crisp UI rendering.

3. **Table & Form Styling (30%)**
   - Inputs include generous padding (`12px 14px`), subtle border styling, rounded corners (`8px`), and interactive focus states with soft shadow rings.
   - The expense table features an accented primary header row, custom uppercase tracking, alternating row background colors (**zebra striping**) for scanning large lists, and smooth hover feedback.

4. **Effective Use of the CSS Box Model (25%)**
   - Applied structured padding (`28px`), controlled margins, clean borders, and uniform border radiuses (`12px`) across layout areas.
   - Distinct sections—the **Page Heading**, **Add Expense Form**, and **Expense Table**—are explicitly structured as standalone visual "cards" with layered box-shadows.
